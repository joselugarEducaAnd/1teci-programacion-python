Objetivo de la sesión

En S1 escribiste programas que ejecutaban siempre las mismas instrucciones. Hoy aprenderás a hacer que un programa tome decisiones: que ejecute unas instrucciones u otras según el valor de los datos.

Al terminar la sesión sabrás:

  • Comparar valores con los operadores relacionales (==, !=, <, >, <=, >=).
  • Combinar varias condiciones con los operadores lógicos (and, or, not).
  • Usar las estructuras if, if/else e if/elif/else para bifurcar el flujo del programa.
  • Dibujar un diagrama de flujo y traducirlo a código Python.

El problema base es un clásico de electrotecnia: dada la intensidad nominal de un circuito, decidir qué calibre comercial de fusible instalar.

Recordatorio: el bucle del programador

NotaEn S2 el paso 2 cobra todavía más importancia

Cuando un programa solo tiene secuencias (como en S1), puedes ir traduciendo línea a línea sin pensar mucho. Cuando un programa toma decisiones, hay que dibujar primero dónde se bifurca el flujo y qué pasa en cada rama. Si lo intentas escribir directamente en Python, te perderás en el segundo elif.

Por eso a partir de hoy: diagrama de flujo en papel antes que código. Sin excepciones. Es exactamente lo mismo que haces en electrotecnia cuando dibujas el esquema antes de montar el circuito.

Concepto 1 — Comparar valores: operadores relacionales

Una comparación es una pregunta que tiene siempre dos respuestas posibles: verdadero o falso. Python las llama True y False.

Operador Pregunta Ejemplo Resultado
== ¿son iguales? 5 == 5 True
!= ¿son distintos? 5 != 3 True
< ¿es menor? 3 < 5 True
> ¿es mayor? 3 > 5 False
<= ¿es menor o igual? 5 <= 5 True
>= ¿es mayor o igual? 5 >= 6 False
Importante== no es lo mismo que =
  • = asigna un valor a una variable: intensidad = 12 significa “guarda 12 en intensidad”.
  • == pregunta si dos valores son iguales: intensidad == 12 significa “¿vale intensidad exactamente 12?”.

Confundir = con == es el error de novato número uno. Si escribes if intensidad = 12: Python te dará un error de sintaxis.

Concepto 2 — La estructura if

El bloque if ejecuta unas instrucciones solo si la condición es verdadera.

intensidad = 12

if intensidad > 10:
    print("Aviso: intensidad alta")

print("Fin del programa")

Si ejecutas este programa con intensidad = 12, sale:

Aviso: intensidad alta
Fin del programa

Si lo ejecutas con intensidad = 5, sale solo:

Fin del programa
WarningLa indentación importa — Python la usa como sintaxis

En la mayoría de lenguajes (C, Java, JavaScript…), los bloques se delimitan con llaves { }. En Python, los bloques se delimitan por la indentación (la sangría al inicio de la línea).

Todo lo que esté indentado dentro del if pertenece al bloque condicional. Lo que vuelva al margen, no.

if intensidad > 10:
    print("Esto se ejecuta solo si la condición es verdadera")
    print("Esto también")
print("Esto se ejecuta SIEMPRE: ha vuelto al margen")

Convención: 4 espacios por nivel (online-python.com lo hace solo cuando pulsas Tab). Si mezclas tabs y espacios, Python se queja. Si la indentación está mal, el programa no hace lo que crees.

Concepto 3 — if / else

else ejecuta unas instrucciones cuando la condición del if es falsa. Es excluyente: o se ejecuta una rama, o la otra, nunca las dos.

intensidad = 5

if intensidad > 10:
    print("Intensidad alta")
else:
    print("Intensidad normal")

Aquí imprimirá "Intensidad normal" porque 5 no es mayor que 10.

Concepto 4 — if / elif / else

Cuando hay más de dos casos posibles, encadenas condiciones con elif (abreviatura de “else if”). Solo se ejecuta el bloque del primer elif cuya condición sea verdadera; el resto se ignoran.

intensidad = 18

if intensidad <= 10:
    print("Bajo consumo")
elif intensidad <= 16:
    print("Consumo medio")
elif intensidad <= 25:
    print("Consumo alto")
else:
    print("Sobrecarga: revisar instalación")

Si intensidad vale 18, Python:

  1. Pregunta intensidad <= 10 → falso, salta.
  2. Pregunta intensidad <= 16 → falso, salta.
  3. Pregunta intensidad <= 25 → verdadero. Imprime "Consumo alto" y se va al final (no comprueba más).
TipEl orden importa

Las condiciones se evalúan de arriba abajo y se ejecuta la primera que sea verdadera. Si las pones mal ordenadas, el programa elige una rama equivocada.

Ejemplo: si en el código de arriba pones elif intensidad <= 25: antes que elif intensidad <= 16:, cualquier valor entre 11 y 16 caería en la rama de “consumo alto” en lugar de “consumo medio”.

Concepto 5 — Diagramas de flujo

Antes de escribir un if/elif/else en Python, lo dibujas en papel como diagrama de flujo. Notación básica:

Convenciones:

  • Óvalo o pastilla: inicio y fin del programa.
  • Paralelogramo: entrada o salida de datos (input, print).
  • Rombo: pregunta o condición (if). Tiene dos flechas de salida etiquetadas con la respuesta (Sí / No, o V / F).
  • Rectángulo: acción o cálculo (x = ..., llamadas a función).
  • Flechas: orden de ejecución.

Concepto 6 — Operadores lógicos

A veces una condición es demasiado simple para describir lo que quieres. Los operadores lógicos combinan varias condiciones en una.

Operador Significado Ejemplo Cuándo es True
and Y x > 0 and x < 10 Cuando las dos son verdaderas
or O x == 0 or x == 5 Cuando al menos una es verdadera
not No not (x > 10) Cuando lo de dentro es falso 
intensidad = 12

if intensidad > 10 and intensidad <= 20:
    print("Entre 10 y 20 amperios")

Esto se imprime porque las dos partes son verdaderas: 12 > 10 (sí) y 12 <= 20 (sí).

Práctica 1 — Selector de calibre de fusible

NotaPestaña: s2_p1_fusible.py

En online-python, abre una pestaña nueva con + y renómbrala s2_p1_fusible.py. Todo el código de esta práctica va en esa pestaña.

Un fusible protege un circuito interrumpiendo la corriente cuando supera un valor de seguridad. Los fusibles comerciales se fabrican en calibres normalizados (no en cualquier valor); el técnico tiene que elegir el inmediatamente superior a la intensidad nominal del circuito para que no salte sin razón en uso normal, pero proteja si hay un fallo.

Tu programa debe pedir la intensidad nominal del circuito (en amperios) y recomendar un fusible elegido entre estos calibres:

NotaCalibres disponibles
Calibre (A)
6
10
16
20
25
32

Si la intensidad nominal supera los 32 A, el programa avisa de que se necesita un fusible especial (fuera del catálogo doméstico habitual).

Paso 1 — Análisis

  • Entrada: intensidad nominal I en amperios (float, la teclea el usuario).
  • Salida: el calibre del fusible recomendado (6, 10, 16, 20, 25 o 32 A) o un aviso si no cabe en el catálogo.
  • Proceso: comparar I con cada calibre, en orden creciente, y elegir el primero que sea mayor o igual.

Paso 2 — Diagrama de flujo

Dibújalo tú primero en papel. Cuando lo tengas, comprueba con este:

Fíjate en el patrón escalera: cada No baja al siguiente nivel. Esto se traduce directamente a if/elif/else en código.

Paso 3 — Pseudocódigo

pedir intensidad I al usuario
si I <= 6:           recomendar fusible de 6 A
si no, si I <= 10:   recomendar fusible de 10 A
si no, si I <= 16:   recomendar fusible de 16 A
si no, si I <= 20:   recomendar fusible de 20 A
si no, si I <= 25:   recomendar fusible de 25 A
si no, si I <= 32:   recomendar fusible de 32 A
si no:               avisar "fuera de catálogo"

Paso 4 — Código Python

# Selector de calibre de fusible

# Entrada
I = float(input("Intensidad nominal del circuito (A): "))

# Decisión
if I <= 6:
    print("Fusible recomendado: 6 A")
elif I <= 10:
    print("Fusible recomendado: 10 A")
elif I <= 16:
    print("Fusible recomendado: 16 A")
elif I <= 20:
    print("Fusible recomendado: 20 A")
elif I <= 25:
    print("Fusible recomendado: 25 A")
elif I <= 32:
    print("Fusible recomendado: 32 A")
else:
    print("Aviso: la intensidad supera el catálogo doméstico. Consultar fusibles industriales.")

Paso 5 — Trazado y validación

Ejecútalo con varios valores y comprueba que el calibre recomendado es el correcto:

Intensidad introducida (A) Fusible esperado
4 6 A
6 6 A (justo encaja)
7 10 A
15 16 A
18 20 A
32 32 A
40 Aviso
TipDetalle importante de los <= vs <

Si I vale exactamente 6, queremos que recomiende el fusible de 6 A — no el de 10. Por eso el operador es <= (menor o igual) y no < (estrictamente menor). Cambiar un operador por otro es uno de los errores típicos del examen: un fallo de criterio que cambia el comportamiento solo en los valores justos.

Práctica 2 (extensión) — Clasificador de dureza Brinell (HB)

NotaPestaña: s2_p2_brinell.py

Solo si has terminado la práctica 1. Abre otra pestaña con + y renómbrala s2_p2_brinell.py. La práctica 1 sigue abierta en su pestaña: no la borres.

La dureza Brinell (HB) es una propiedad de los materiales medida por la huella que deja una bola de acero comprimida sobre la superficie. Permite clasificar los materiales de forma orientativa según su comportamiento mecánico:

Rango de HB Clasificación Ejemplos típicos
HB < 100 Blando Aluminio recocido, plomo, latón blando
100 ≤ HB < 200 Semi-duro Latón duro, aluminio templado, acero recocido
200 ≤ HB < 400 Duro Acero al carbono, hierro fundido
HB ≥ 400 Muy duro Acero templado, herramientas de corte

Escribe un programa que:

  1. Pida al usuario el valor HB de un material.
  2. Imprima a qué clase pertenece (blando, semi-duro, duro o muy duro).
  3. Extensión (si te quedas con ganas): pregunte además si el material se va a usar para “estructura” o “herramienta de corte”. Si la respuesta es “herramienta” pero HB < 400, el programa avisa de que el material no es adecuado.
SoluciónSolución básica (clic para desplegar) 
# Clasificador de dureza Brinell

# Entrada
HB = float(input("Dureza HB del material: "))

# Decisión
if HB < 100:
    clase = "blando"
elif HB < 200:
    clase = "semi-duro"
elif HB < 400:
    clase = "duro"
else:
    clase = "muy duro"

# Salida
print("Material con HB =", HB, "→ clase:", clase)

Comprobaciones:

HB introducido Clase esperada
80 blando
100 semi-duro (justo en el límite)
250 duro
500 muy duro
SoluciónSolución de la extensión con aplicación (clic para desplegar) 
# Clasificador de dureza Brinell con recomendación de uso

HB = float(input("Dureza HB del material: "))
uso = input("Uso previsto (estructura / herramienta): ")

# Clasificación
if HB < 100:
    clase = "blando"
elif HB < 200:
    clase = "semi-duro"
elif HB < 400:
    clase = "duro"
else:
    clase = "muy duro"

# Recomendación
if uso == "herramienta" and HB < 400:
    recomendacion = "NO adecuado: una herramienta de corte necesita HB >= 400"
else:
    recomendacion = "Adecuado para el uso indicado"

# Salida
print("Material con HB =", HB, "→ clase:", clase)
print(recomendacion)

Aquí entra en juego el operador and: la advertencia se imprime solo si uso == "herramienta" Y, además, HB < 400. Cualquiera de las dos condiciones por separado no basta.

Cierre — Trazado en pizarra

Vamos a trazar juntos el selector de fusible con I = 18:

Línea evaluada Resultado ¿Entra en el bloque?
if I <= 6: 18 <= 6 → False No
elif I <= 10: 18 <= 10 → False No
elif I <= 16: 18 <= 16 → False No
elif I <= 20: 18 <= 20 → True Sí — imprime “Fusible recomendado: 20 A”
elif I <= 25: — (se salta, ya entró en una rama anterior)
elif I <= 32: — (se salta)
else: — (se salta)

Recuerda: en cuanto un elif se evalúa como verdadero y entra, todos los siguientes se saltan. Es exactamente igual que en un diagrama de flujo: una vez sigues la flecha del “Sí”, no vuelves al rombo.
