Objetivo de la sesión

En S3 usaste for para repetir un cálculo un número conocido de veces (range(10) da exactamente 10 iteraciones). Hoy aprendes:

  • A repetir mientras se cumpla una condición que no sabes a priori cuándo dejará de cumplirse, con el bucle while.
  • A guardar una colección de datos en una variable, usando listas.
  • A recorrer una lista con for x in lista: y a calcular sus estadísticos.

El problema base es práctico de laboratorio puro: el usuario introduce N medidas experimentales una a una hasta que escribe fin, y el programa calcula media, mínimo, máximo y rango. Hasta ahora todos los programas pedían un número fijo de datos al inicio; este pide “todos los que haga falta”.

Recordatorio: el bucle del programador

NotaHoy aparece un peligro nuevo: los bucles que no terminan

Con for, sabes que el bucle hace exactamente las iteraciones del range. Con while, eres tú quien decide cuándo parar. Si te equivocas en la condición o se te olvida actualizar la variable que la controla, el programa se queda repitiendo eternamente. En online-python verás un botón STOP rojo cuando esto pase — púlsalo, repasa el código, vuelve a intentarlo.

Trazar el bucle en papel antes de ejecutar evita el 90 % de los bucles infinitos. Es la mejor inversión de cinco minutos que puedes hacer en esta sesión.

Concepto 1 — El bucle while

La sintaxis es:

while condición:
    instrucciones que se repiten

Mientras la condición sea verdadera, Python repite el bloque. En cuanto sea falsa, sale del bucle y sigue por debajo.

Ejemplo trivial: contar de 1 a 5 con while.

n = 1
while n <= 5:
    print(n)
    n = n + 1
print("Fin")

Trazado:

Iteración n (antes de la línea print) Imprime n (después del incremento)
1ª 1 1 2
2ª 2 2 3
3ª 3 3 4
4ª 4 4 5
5ª 5 5 6
6ª 6 (sale del bucle) —

Al final imprime Fin. El while se sale en cuanto n = 6 porque 6 <= 5 es falso.

Importantefor vs while
  • Usa for cuando sabes el número exacto de iteraciones (for i in range(10), for m in mi_lista).
  • Usa while cuando dependes de una condición externa (que el usuario escriba una palabra clave, que un valor caiga por debajo de un umbral, que un sensor envíe algo).

Casi cualquier bucle se podría escribir de las dos formas, pero hacerlo del lado natural ahorra mucha complicación.

WarningEl bucle infinito

Mira este ejemplo aparentemente inocente:

n = 1
while n <= 5:
    print(n)

¿Notas la diferencia con el anterior? Falta el n = n + 1. Sin esa línea, n se queda en 1 para siempre, la condición sigue siendo verdadera para siempre, y el bucle no acaba. En online-python verás cómo la consola va imprimiendo 1 una y otra vez, y tendrás que pulsar STOP.

Regla: en todo while debe haber algo en el cuerpo que cambie la condición. Si no, es un bucle infinito.

Concepto 2 — El patrón centinela

Patrón muy frecuente: pedir datos al usuario hasta que escriba una palabra clave (un “centinela”). El centinela típico es "fin", "stop", "q" o un número imposible como -1.

entrada = input("Dame algo (o 'fin' para terminar): ")
while entrada != "fin":
    print("Recibido:", entrada)
    entrada = input("Dame algo (o 'fin' para terminar): ")
print("Programa terminado")

Detalles importantes:

  1. Pides el primer dato antes del bucle (línea 1). Así la condición ya tiene algo que comprobar la primera vez.
  2. Vuelves a pedir dato dentro del bucle (última línea del cuerpo). Si no, el programa se queda mirando para siempre la misma entrada y no acaba nunca.

Concepto 3 — Las listas

Una lista es una variable que guarda varios valores en orden. Puedes pensar en ella como una fila de casilleros numerados desde 0.

Crear una lista vacía:

medidas = []

Crear una lista con valores iniciales:

calibres = [6, 10, 16, 20, 25, 32]

Operaciones básicas:

Operación Sintaxis Ejemplo
Longitud len(lista) len(calibres) → 6
Acceso por índice lista[i] calibres[0] → 6; calibres[2] → 16
Añadir al final lista.append(valor) medidas.append(4.7)
Recorrer con for for x in lista: ver más abajo
ImportanteLos índices empiezan en 0

El primer elemento es lista[0], no lista[1]. El último es lista[len(lista) - 1]. Pedir calibres[6] cuando la lista tiene solo 6 elementos da error (IndexError): los índices válidos son 0, 1, 2, 3, 4, 5.

Python admite también índices negativos: calibres[-1] es el último elemento; calibres[-2] el penúltimo. Útil cuando no quieres calcular len a mano.

Concepto 4 — Recorrer una lista con for

La forma más limpia de recorrer una lista en Python:

calibres = [6, 10, 16, 20, 25, 32]
for c in calibres:
    print(c)

En cada iteración, c toma sucesivamente cada uno de los valores de la lista. No necesitas índices.

Para calcular la suma:

total = 0
for c in calibres:
    total = total + c
print("Suma:", total)   # 109

Es el mismo patrón “acumulador” de S3, pero ahora aplicado a una lista en lugar de a un range.

Tip¿Y si necesito el índice?

A veces sí lo necesitas (por ejemplo, para imprimir “Medida 1: 4.7, Medida 2: 4.8…”). Entonces iteras sobre el range(len(lista)) y accedes con lista[i]:

for i in range(len(medidas)):
    print("Medida", i + 1, ":", medidas[i])

Pero si solo quieres leer los valores, for m in medidas: es siempre más limpio.

Práctica 1 — Estadística de medidas experimentales

NotaPestaña: s4_p1_estadistica.py

En online-python, abre una pestaña nueva con + y renómbrala s4_p1_estadistica.py.

En el laboratorio de Tecnología repites una medida varias veces (por ejemplo, la longitud de una pieza con un calibre) y luego haces estadísticos para estimar el valor “verdadero”. Tu programa va a automatizar eso:

  1. Pide medidas una a una al usuario.
  2. Termina cuando el usuario escribe fin.
  3. Imprime: número de medidas, media, mínimo, máximo y rango.

Paso 1 — Análisis

  • Entrada: una secuencia de medidas (float) introducidas por el usuario, terminada con la palabra "fin".
  • Salida: cinco valores: número de medidas, media, mínimo, máximo y rango.
  • Proceso: un bucle while con patrón centinela guarda las medidas en una lista. Después, un for recorre la lista para calcular suma, mínimo y máximo.

Paso 2 — Pseudocódigo

medidas <- lista vacía
entrada <- pedir primera medida (o "fin")
mientras entrada != "fin":
    convertir entrada a número y añadirla a medidas
    entrada <- pedir siguiente medida (o "fin")

si la lista está vacía:
    avisar y terminar
si no:
    suma <- 0
    mínimo <- primera medida
    máximo <- primera medida
    para cada m en medidas:
        suma <- suma + m
        si m < mínimo: mínimo <- m
        si m > máximo: máximo <- m
    media <- suma / longitud de medidas
    rango <- máximo - mínimo
    imprimir n, media, mínimo, máximo, rango

Paso 3 — Código Python

# Estadística de medidas experimentales

# Recolección de medidas con patrón centinela
medidas = []
entrada = input("Introduce una medida (o 'fin' para terminar): ")
while entrada != "fin":
    medidas.append(float(entrada))
    entrada = input("Introduce una medida (o 'fin' para terminar): ")

# Cálculo de estadísticos
n = len(medidas)
if n == 0:
    print("No se introdujo ninguna medida.")
else:
    suma = 0
    minimo = medidas[0]
    maximo = medidas[0]
    for m in medidas:
        suma = suma + m
        if m < minimo:
            minimo = m
        if m > maximo:
            maximo = m
    media = suma / n
    rango = maximo - minimo

    print("---")
    print("Número de medidas:", n)
    print("Media:", media)
    print("Mínimo:", minimo)
    print("Máximo:", maximo)
    print("Rango:", rango)

Paso 4 — Trazado y validación

Ejecútalo con esta secuencia de entradas:

4.7
4.8
4.6
4.9
4.7
fin

Resultado esperado:

  • Número de medidas: 5
  • Media: 4.74
  • Mínimo: 4.6
  • Máximo: 4.9
  • Rango: 0.3 (puede salirte 0.299999… por el redondeo de los float; no es un error tuyo)

Comprueba también el caso límite: si escribes fin en la primera entrada (sin meter ninguna medida), debe imprimir el aviso y no romperse.

TipPor qué inicializamos minimo y maximo con medidas[0]

Podrías pensar en inicializar minimo = 999999 y maximo = -999999 (valores imposibles). Funciona en la práctica, pero es feo: si las medidas son temperaturas en Kelvin, esos “imposibles” podrían no serlo. Lo correcto y robusto es arrancar con el primer valor real de la lista (medidas[0]) y comparar desde ahí.

Por eso comprobamos antes que n != 0: si la lista está vacía, medidas[0] daría error.

Práctica 2 (extensión) — Detección de valores anómalos

NotaPestaña: s4_p2_outliers.py

Solo si has terminado la práctica 1. Abre otra pestaña con + y renómbrala s4_p2_outliers.py.

Cuando una medida del laboratorio se desvía demasiado de la media, sospechamos que hay un error experimental: una lectura mal hecha, un instrumento mal calibrado en ese intento, una anotación equivocada. Esas medidas se llaman outliers y suelen descartarse.

Modifica el programa anterior para que, después de imprimir los estadísticos, haga una segunda pasada por la lista y muestre todas las medidas cuya desviación absoluta respecto a la media supere un umbral introducido por el usuario.

Conceptos nuevos:

  • Valor absoluto: abs(x) devuelve |x|. Por ejemplo, abs(-3.2) → 3.2. Necesario porque una desviación puede ser positiva o negativa, y queremos comparar la magnitud.
  • Segunda pasada: vuelves a recorrer la misma lista con un for para hacer otro cálculo. Las listas se pueden recorrer todas las veces que quieras.
SoluciónSolución (clic para desplegar) 
# Estadística de medidas + detección de outliers

medidas = []
entrada = input("Introduce una medida (o 'fin' para terminar): ")
while entrada != "fin":
    medidas.append(float(entrada))
    entrada = input("Introduce una medida (o 'fin' para terminar): ")

n = len(medidas)
if n == 0:
    print("No se introdujo ninguna medida.")
else:
    # Estadísticos (igual que en la práctica 1)
    suma = 0
    minimo = medidas[0]
    maximo = medidas[0]
    for m in medidas:
        suma = suma + m
        if m < minimo:
            minimo = m
        if m > maximo:
            maximo = m
    media = suma / n
    rango = maximo - minimo

    print("---")
    print("Número de medidas:", n)
    print("Media:", media)
    print("Mínimo:", minimo)
    print("Máximo:", maximo)
    print("Rango:", rango)

    # Detección de outliers (segunda pasada)
    umbral = float(input("Umbral de desviación absoluta para outliers: "))
    print("---")
    print("Outliers (desviación >", umbral, "respecto a la media):")
    hay_outliers = False
    for m in medidas:
        if abs(m - media) > umbral:
            print("  ", m, "  (desviación:", m - media, ")")
            hay_outliers = True
    if not hay_outliers:
        print("  (ninguno)")

Comprobación: con las medidas 4.7, 4.8, 4.6, 4.9, 4.7, 5.5, fin y umbral 0.5, la única medida que sale como outlier es 5.5 (desviación de unos +0.66 respecto a la media 4.87).

Cierre — Trazado en pizarra

Antes de irte, traza este fragmento — es exactamente el tipo de pregunta que entra en el examen:

nums = [3, 7, 1, 8, 2]
mejor = nums[0]
for x in nums:
    if x > mejor:
        mejor = x
print(mejor)
Iteración x ¿x > mejor? mejor después
Antes del bucle — — 3
1ª 3 3 > 3 → No 3
2ª 7 7 > 3 → Sí 7
3ª 1 1 > 7 → No 7
4ª 8 8 > 7 → Sí 8
5ª 2 2 > 8 → No 8

Salida: 8. (Es el máximo de la lista, calculado con el patrón “máximo en un bucle” de S3.)
