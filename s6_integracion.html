Concepto único — math.exp para la exponencial

La fórmula de la descarga del condensador es:

\[V(t) = V_0 \cdot e^{-t / (R \cdot C)}\]

Para usarla en Python necesitas la función math.exp(x) que calcula \(e^x\). Vive dentro del módulo math de la biblioteca estándar, así que la primera línea de tu programa será:

import math

Después puedes escribir math.exp(-t / (R * C)) donde lo necesites.

TipRecordatorio físico

Cuando un condensador cargado a V₀ se descarga a través de una resistencia R, la tensión entre sus bornes cae exponencialmente con constante de tiempo τ = R·C (en segundos, si R está en ohmios y C en faradios). A los t = τ segundos, la tensión es aproximadamente el 37 % de la inicial; a los t = 5τ, prácticamente cero.

Lo viste a mano en la unidad de circuitos electrónicos de este curso. Hoy lo automatizamos: el ordenador genera la tabla t, V(t) con todos los pasos que tú quieras.

Práctica 1 — Simulación de la descarga de un condensador

NotaPestaña: s6_p1_condensador.py

En online-python, abre una pestaña nueva con + y renómbrala s6_p1_condensador.py. Todo el código de esta práctica va en esa pestaña.

Vas a escribir un programa que:

  1. Pide al usuario los datos del circuito: V0 (V), R (Ω), C (F), t_final (s) y dt (s).
  2. Define una función V(t, V0, R, C) que devuelve la tensión en el instante t.
  3. Itera con un bucle desde t = 0 hasta t = t_final con paso dt, guardando cada V(t) en una lista.
  4. Imprime la tabla t, V por consola.
  5. Al final, imprime también la constante de tiempo τ = R·C y la tensión mínima alcanzada en la tabla.

Paso 1 — Análisis

  • Entradas: V0, R, C, t_final, dt (los cinco como float).
  • Salida: una tabla t | V(t) + dos resultados de cierre (τ y V mínima).
  • Proceso: bucle for sobre el índice del paso, función propia para V(t), lista para guardar los valores y un mínimo recorriendo la lista.

Paso 2 — Pseudocódigo

importar math

definir V(t, V0, R, C) que devuelve V0 · exp(-t / (R·C))

pedir V0, R, C, t_final, dt al usuario
calcular n_pasos = parte entera de (t_final / dt) + 1
calcular tau = R · C

tensiones <- lista vacía
imprimir cabecera "  t      V"

para i desde 0 hasta n_pasos - 1:
    t = i · dt
    v = V(t, V0, R, C)
    añadir v a tensiones
    imprimir t, v

V_min <- tensiones[0]
para cada v en tensiones:
    si v < V_min: V_min <- v

imprimir tau y V_min

Reconocerás patrones: el “truco del índice” para iterar con paso decimal viene de S3, la lista y el cálculo del mínimo vienen de S4, la función V(t, …) viene de S5.

Paso 3 — Código Python

Escríbelo línea a línea, sin copiar y pegar bloques completos.

# Simulación de la descarga de un condensador
# S6 · Integración — TECI I

import math


def V(t, V0, R, C):
    """Devuelve la tensión en bornes del condensador en el instante t (V).

    Modelo: V(t) = V0 · exp(-t / (R·C)).
    Espera R > 0 y C > 0.
    """
    return V0 * math.exp(-t / (R * C))


# Entradas
V0      = float(input("Tensión inicial V0 (V): "))
R       = float(input("Resistencia R (ohmios): "))
C       = float(input("Capacidad C (faradios): "))
t_final = float(input("Tiempo final (s): "))
dt      = float(input("Paso de tiempo dt (s): "))

# Cálculos previos
n_pasos = int(t_final / dt) + 1
tau     = R * C

# Bucle principal: tabla y lista de tensiones
tensiones = []
print("  t        V")
for i in range(n_pasos):
    t = i * dt
    v = V(t, V0, R, C)
    tensiones.append(v)
    print(t, v)

# Mínimo de la lista
V_min = tensiones[0]
for v in tensiones:
    if v < V_min:
        V_min = v

# Resultados de cierre
print("---")
print("Constante de tiempo tau = R·C =", tau, "s")
print("Tensión mínima alcanzada en la tabla:", V_min, "V")

Paso 4 — Trazado y validación

Ejecútalo con un caso conocido: V0 = 10 V, R = 1000 Ω, C = 0.001 F, t_final = 5 s, dt = 1 s.

Eso da τ = 1·10³ · 10⁻³ = 1 s. La tabla esperada (redondeando a tres cifras):

t (s) V (V)
0 10.000
1 3.679
2 1.353
3 0.498
4 0.183
5 0.067

A los t = τ = 1 s, la tensión es 10 · e⁻¹ ≈ 3.679 V, que es justo el 37 % de los 10 V iniciales (✓ recordatorio físico). A los 5τ, ha caído por debajo del 1 % de la inicial.

La tensión mínima de la tabla, en este caso, es la última: V_min ≈ 0.067 V.

TipSi las cifras no te coinciden

Lo más probable es que hayas equivocado el signo del exponente (exp(t/(R·C)) en lugar de exp(-t/(R·C))). Sin el menos, la tensión crece exponencialmente — irías hacia el infinito en lugar de hacia cero. Es un error muy típico, y se detecta justo así: con un caso conocido del que sabes el resultado a ojo.

Escribe lo que imprime este programa por consola:

x = 7
y = 4
if x > y and x % 2 == 1:

elif x > y or y == 4:

SoluciónSolución (clic para desplegar)

Pregunta 2 — Detección y corrección de errores (bloque B)

El siguiente programa pretende calcular la media de una lista de notas, pero tiene dos errores: uno de sintaxis y uno de lógica. Identifícalos, indica la línea de cada uno y reescribe el programa corregido.

notas = [4, 7, 5, 9, 6]
suma = 0
for n in notas
    suma = suma + n
media = suma / 5
print("Media:" media)
SoluciónSolución (clic para desplegar)

Errores de sintaxis:

  • Línea 3 (for n in notas): falta el : al final. Python da SyntaxError. Correcto: for n in notas:.
  • Línea 6 (print("Media:" media)): falta una coma entre "Media:" y media. Correcto: print("Media:", media).

Error de lógica:

  • Línea 5 (media = suma / 5): la 5 está hardcodeada y solo funciona si la lista tiene exactamente cinco elementos. Si añades una nota o quitas una, la media sale mal. Lo correcto es dividir entre el número real de elementos: media = suma / len(notas).

Programa corregido:

notas = [4, 7, 5, 9, 6]
suma = 0
for n in notas:
    suma = suma + n
media = suma / len(notas)
print("Media:", media)

Salida: Media: 6.2.

Pregunta 3 — Trazado paso a paso (bloque C)

Rellena la tabla de trazado y escribe la salida por consola de este programa:

total = 0
for i in range(1, 6):
    if i % 2 == 0:
        total = total + i
    else:
        total = total - i
print(total)

2ª ? ? ? ?
3ª ? ? ? ?
4ª ? ? ? ?
5ª ? ? ? ?
SoluciónSolución (clic para desplegar)

range(1, 6) da 1, 2, 3, 4, 5 (cinco iteraciones; el 6 NO entra).

Iteración i i % 2 == 0 rama tomada total después
Antes del bucle — — — 0
1ª 1 1 % 2 == 0 → No else: total - i 0 - 1 = -1
2ª 2 2 % 2 == 0 → Sí if: total + i -1 + 2 = 1
3ª 3 3 % 2 == 0 → No else: total - i 1 - 3 = -2
4ª 4 4 % 2 == 0 → Sí if: total + i -2 + 4 = 2
5ª 5 5 % 2 == 0 → No else: total - i 2 - 5 = -3

Salida: -3. (Es la suma alternada -1 + 2 - 3 + 4 - 5.)

Pregunta 4 — Escritura de código (bloque D)

Escribe una función clasifica_nota(nota) que reciba una nota numérica (de 0 a 10) y devuelva una de las cadenas "Insuficiente", "Suficiente", "Bien", "Notable" o "Sobresaliente", según estos rangos:

Rango Calificación
nota < 5 "Insuficiente"
5 ≤ nota < 6 "Suficiente"
6 ≤ nota < 7 "Bien"
7 ≤ nota < 9 "Notable"
nota ≥ 9 "Sobresaliente"

Justo debajo de la función, escribe dos líneas que prueben la función con nota = 6.5 y nota = 9.2 imprimiendo los resultados por consola.

SoluciónSolución (clic para desplegar) 
def clasifica_nota(nota):
    """Devuelve la calificación textual correspondiente a una nota numérica de 0 a 10."""
    if nota < 5:
        return "Insuficiente"
    elif nota < 6:
        return "Suficiente"
    elif nota < 7:
        return "Bien"
    elif nota < 9:
        return "Notable"
    else:
        return "Sobresaliente"


print(clasifica_nota(6.5))   # Bien
print(clasifica_nota(9.2))   # Sobresaliente

Detalles del estilo recomendado:

  • Las condiciones de los elif aprovechan que ya se ha descartado el caso anterior: en el segundo elif, escribir nota < 6 basta porque el if anterior ya ha filtrado los nota < 5. No hace falta 5 <= nota < 6.
  • Cada rama termina con return. En cuanto se ejecuta uno, la función se sale; no hace falta break ni nada similar.
  • El último caso (nota ≥ 9) se cubre con un else final, no con otro elif. Es más limpio y garantiza que siempre se devuelve algo.
