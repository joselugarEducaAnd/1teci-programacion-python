7. Listas

Qué vas a aprender en esta página

  • a guardar muchos datos en una sola variable: una lista;
  • a leer cualquier dato de la lista por su posición;
  • a recorrer una lista entera con for;
  • a buscar un valor en una lista y a saber dónde está el mayor.

Por qué hacen falta las listas

En la página 5 calculaste la estadística de unas medidas sin guardarlas: cada medida se usaba al llegar y después se perdía. Eso no sirve si luego quieres volver a mirarlas, por ejemplo para ver cuáles se alejan de la media, que solo se conoce al final. Una lista resuelve el problema: es una sola variable que guarda muchos datos en orden, como una fila de casilleros numerados.

Una lista se escribe con los datos entre corchetes y separados por comas:

calibres = [6, 10, 16, 20, 25, 32]
medidas = []          # lista vacía, se rellenará después

La posición de cada dato: el índice

Cada dato de la lista ocupa una posición, que se llama índice. Lo importante: el primero está en la posición 0, no en la 1. Para leer un dato se escribe el nombre de la lista y su posición entre corchetes:

Si pides una posición que no existe, por ejemplo calibres[6] en una lista de 6 datos, el programa se detiene con un error IndexError («error de índice»). Las posiciones válidas van de 0 a len(lista) - 1.

Recorrer una lista

Para hacer algo con cada dato de la lista se usa for. Hay dos formas, según lo que necesites:

  • Si solo necesitas los datos: for m in medidas:. En cada vuelta, m vale el siguiente dato de la lista.
  • Si además necesitas la posición: for i in range(len(medidas)):. En cada vuelta, i es la posición y medidas[i] es el dato.
medidas = [4.7, 4.8, 4.6, 4.9]
for m in medidas:
    print(m)
for i in range(len(medidas)):
    print("Medida", i + 1, ":", medidas[i])

Ejemplo paso a paso: ¿está este calibre en el catálogo?

Problema: tenemos la lista de calibres de fusible que vende un proveedor. Queremos saber si tiene uno concreto.

Idea: recorremos la lista entera con una variable que hace de «chivato» y que se llama bandera. Empieza valiendo False («no lo he encontrado») y, si en algún momento aparece el calibre buscado, se pone a True. Al terminar el recorrido, la bandera dice si estaba o no.

# Ejemplo resuelto: ¿está este calibre en el catálogo?
calibres = [6, 10, 16, 20, 25, 32]
buscado = int(input("Calibre buscado (A): "))
encontrado = False
for c in calibres:
    if c == buscado:
        encontrado = True
if encontrado:
    print("Sí está en el catálogo")
else:
    print("No está en el catálogo")

¿En qué posición está el mayor?

En la página 5 aprendiste a encontrar el máximo. Ahora, además, queremos saber dónde está. En lugar de guardar el valor máximo, guardamos su posición en una variable, pos_max, que empieza en 0 (el primer dato). Recorremos la lista y, cada vez que un dato es mayor que el que está en pos_max, cambiamos pos_max por la posición del nuevo:

pos_max = 0
for i in range(len(medidas)):
    if medidas[i] > medidas[pos_max]:
        pos_max = i

Lo que tienes que saber de esta página

  • Una lista guarda varios datos en orden: [6, 10, 16]; [] es una lista vacía.

  • len(lista) da cuántos datos hay y lista.append(x) añade uno al final.
  • Recorrer: for x in lista (los datos) o for i in range(len(lista)) (las posiciones).
  • Para buscar se usa una bandera que empieza en False.
