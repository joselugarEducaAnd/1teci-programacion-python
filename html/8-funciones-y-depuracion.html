Qué es una función

Ya has usado funciones que trae Python: print, input, round, len… Cada una hace una tarea concreta y basta con llamarla por su nombre. Ahora vas a crear las tuyas. Una función es un trozo de programa con nombre propio que se escribe una vez y se puede usar todas las veces que haga falta. Es muy útil cuando un mismo cálculo aparece varias veces.

Así se crea y se usa una función que calcula el cuadrado de un número:

def cuadrado(x):
    return x * x

print(cuadrado(5))
print(cuadrado(1.5))

En la consola

25
2.25
  • def («definir») crea la función. Detrás van su nombre, unos paréntesis con los datos que necesita y dos puntos. Esos datos se llaman parámetros: aquí hay uno, x.
  • Las líneas sangradas son el cuerpo de la función: lo que hace.
  • return («devolver») indica el resultado que la función entrega a quien la usó, y la termina.
  • Definir una función no la ejecuta. Se ejecuta cuando se la llama: cuadrado(5). El valor que pones al llamarla (el 5) se guarda en el parámetro x y la función hace el cálculo con él.

Lo que pasa dentro de la función se queda dentro

Las variables que se crean dentro de una función solo existen mientras la función se está ejecutando; se llaman variables locales. Fuera de la función no se pueden usar. Este programa intenta usar fuera la variable resultado, que es local, y falla:

def doble(x):
    resultado = x * 2
    return resultado

y = doble(5)
print(y)
print(resultado)

En la consola (del mensaje de error, solo la última línea)

10
NameError: name 'resultado' is not defined

El 10 sale bien, porque llega a través del return. Después aparece el error NameError: «name 'resultado' is not defined» significa «el nombre resultado no está definido». La única forma de sacar un valor de una función es devolverlo con return.

¿Y si se te olvida el return? Entonces la función hace el cálculo, pero no devuelve nada. Python no da ningún error: la llamada vale None, que en Python significa «nada»:

def doble(x):
    resultado = x * 2

y = doble(5)
print(y)

En la consola

None

Es un error de lógica, de los que no avisan: si al probar una función te sale None, lo primero que tienes que mirar es si le falta el return.

Ejemplo paso a paso: funciones para circuitos

Problema: en electricidad se calculan una y otra vez las mismas tres cosas: la resistencia equivalente de dos resistencias en serie (se suman), la de dos en paralelo (el producto dividido entre la suma) y la intensidad por la ley de Ohm (I = V / R). Vamos a escribir una función para cada una.

Debajo de cada def hay un texto entre triples comillas: es el docstring, una explicación de lo que hace la función. Escríbelo siempre en tus funciones.

# Ejemplo resuelto: biblioteca de funciones eléctricas
def Rserie(R1, R2):
    """Resistencia equivalente de R1 y R2 en serie (ohmios)."""
    return R1 + R2

def Rparalelo(R1, R2):
    """Resistencia equivalente de R1 y R2 en paralelo (ohmios)."""
    return R1 * R2 / (R1 + R2)

def intensidad(V, R):
    """Ley de Ohm: intensidad en amperios."""
    return V / R

Req = Rserie(100, 220)
print("Serie:", Req, "ohmios ->", intensidad(12, Req), "A")
Req = Rparalelo(220, 330)
print("Paralelo:", Req, "ohmios ->", round(intensidad(12, Req), 4), "A")

En la consola

Serie: 320 ohmios -> 0.0375 A
Paralelo: 132.0 ohmios -> 0.0909 A

Con las funciones escritas, calcular cualquier otro circuito es tan sencillo como volver a llamarlas con otros datos, sin reescribir ninguna fórmula.

Trazar un programa con funciones

Cuando la traza llega a una llamada, se «entra» en la función: sus parámetros toman los valores de la llamada y se siguen sus líneas. Al llegar a return, se «sale» con el resultado y se continúa donde se estaba. Ejemplo:

def f(x, y):
    z = x + 2 * y
    return z

a = f(3, 4)

Depurar: encontrar y corregir errores

Depurar es buscar los errores de un programa y corregirlos. Hay tres clases de errores:

Tipo de errorCuándo se notaEjemplos
de sintaxisantes de empezar: Python no entiende lo que has escrito y no ejecuta nadafalta un :, un paréntesis o unas comillas
de ejecucióna mitad del programa: se detiene con un mensajeValueError, NameError, dividir entre cero
de lógicanunca: el programa termina sin quejarse, pero el resultado está malun < donde iba <=, una fórmula equivocada

Los más peligrosos son los de lógica, porque no avisan. Este programa debería calcular la media de 4, 6 y 8, que es 6:

def media(lista):
    suma = 0
    for x in lista:
        suma = x
    return suma / len(lista)

print(media([4, 6, 8]))

En la consola

2.6666666666666665

Sale 2.67 y no 6. Para encontrar el error, sigue estos pasos:

  1. Prueba con un caso cuyo resultado conozcas. Sabemos que debe salir 6 y sale 2.67: hay un error.
  2. Traza el programa, a mano o con Visualize, y mira cómo cambia suma: vale 4, después 6 y después 8. No va sumando; solo guarda el último dato.
  3. Localiza la línea culpable: suma = x debería ser suma = suma + x.
  4. Corrige y vuelve a probar con el mismo caso, para confirmar que ahora da 6.

Otra técnica muy útil: añadir print provisionales que escriban los valores intermedios y quitarlos cuando todo funcione. El botón Debug de online-python permite además parar el programa en una línea y avanzar instrucción a instrucción.

Un condensador cargado a una tensión V0 que se descarga a través de una resistencia R va perdiendo tensión cada vez más despacio. En el instante t, su tensión es V = V0 · e−t/(R·C), donde C es la capacidad del condensador. El producto R·C se llama constante de tiempo (τ): cuando han pasado τ segundos, la tensión ha bajado al 37 % de la inicial.

Qué tienes que hacer: un programa que:

  2. pida V0, R, C, el tiempo final y el paso de tiempo;
  3. con un bucle, calcule la tensión en cada instante, la guarde en una lista y escriba una tabla;
  4. al final, escriba la constante de tiempo y la última tensión de la lista.

Lo que tienes que saber de esta página

  • def nombre(parámetros): crea una función; return devuelve su resultado y la termina.
  • Una función no se ejecuta hasta que se la llama: nombre(datos). Los datos de la llamada se guardan en los parámetros, en el mismo orden.
  • Las variables creadas dentro de una función no existen fuera. Si falta el return, la función devuelve None («nada»).
  • Errores de sintaxis (Python no lo entiende), de ejecución (se detiene) y de lógica (el resultado está mal y no avisa).
  • Depurar: probar con un caso conocido, trazar, localizar la línea, corregir y volver a probar.

Clasifica
