Las variables

Una variable es como una caja con una etiqueta: la etiqueta es el nombre, y dentro se guarda un dato. Para crear una variable y guardar algo en ella se escribe el nombre, el signo = y el valor:

tension = 12
intensidad = 2
potencia = tension * intensidad

La primera línea crea una caja llamada tension y guarda dentro el número 12. La tercera calcula 12 · 2 y guarda el resultado, 24, en una caja nueva llamada potencia. A partir de ese momento, cada vez que escribas potencia en el programa, Python usará el 24.

El signo = no significa lo mismo que en matemáticas

En Python, = quiere decir «calcula lo que hay a la derecha y guárdalo en la variable de la izquierda». Por eso esta línea, que en matemáticas sería imposible, es correcta: n = n + 1. Significa «coge el valor que tiene ahora n, súmale 1 y guarda el resultado otra vez en n». Si n valía 5, después vale 6.

Para poner nombre a las variables hay unas normas:

  • no pueden llevar espacios ni empezar por un número;
  • tampoco se ponen tildes ni eñes: Python las admite, pero no es costumbre y dan problemas al compartir el programa;
  • se escriben en minúsculas y, si son varias palabras, unidas con un guion bajo: velocidad_kmh;
  • Python distingue mayúsculas y minúsculas: v y V son dos variables distintas;
  • conviene que el nombre diga qué guarda: velocidad se entiende mejor que x.

Un valor que no cambia nunca en todo el programa (por ejemplo, los milímetros que tiene una pulgada) se llama constante y, por costumbre, se escribe en mayúsculas: MM_POR_PULGADA = 25.4.

Los tipos de datos

No todos los datos son iguales: no es lo mismo un número que un texto. Cada dato tiene un tipo, y Python lo deduce solo según cómo lo escribas. La instrucción type() te dice el tipo de un dato:

intensidad = 3          # int: número entero
tension = 12.5          # float: número con decimales
unidad = "V"            # str: texto
encendido = True        # bool: verdadero o falso
print(type(intensidad), type(tension), type(unidad), type(encendido))

Python respeta el mismo orden que en matemáticas: primero las potencias, después multiplicaciones y divisiones, y por último sumas y restas. Por eso 2 + 3 * 4 da 14 y no 20. Ejemplo paso a paso: de pulgadas a milímetros

Problema: las medidas de muchas herramientas y tuberías vienen en pulgadas. Queremos un programa que pase una medida en pulgadas a milímetros. Una pulgada son 25,4 mm.

1. Analizar. Entrada: la medida en pulgadas. Salida: la medida en milímetros. Proceso: multiplicar las pulgadas por 25,4.

2. Planificar.

pedir la medida en pulgadas
multiplicarla por 25,4
escribir el resultado

3. Escribir el código.

# Ejemplo resuelto: de pulgadas a milímetros
MM_POR_PULGADA = 25.4                     # constante: no cambia nunca

pulgadas = float(input("Medida en pulgadas: "))
milimetros = pulgadas * MM_POR_PULGADA
print(pulgadas, "pulgadas son", milimetros, "mm")

En la segunda línea aparece algo nuevo: float(input(...)). input devuelve siempre un texto, aunque el usuario escriba un número; float(...) convierte ese texto en un número con decimales para poder calcular con él. En la página 3 lo verás con más detalle. De momento, úsalo así cada vez que tengas que pedir un número.
